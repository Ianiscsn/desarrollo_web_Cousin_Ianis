Para lanzar el sitio web, es necesario lanzar el archivo html llamado index. Decidí crear un documento css común para todos los documentos html pero separé el código según cada página. Además, creé tres documentos JavaScript, el primero (auxil_formulario.js) se encarga de todas las tareas relacionadas con el formulario de la página Agregar_actividad excepto la validación de los inputs, el segundo (conf_formulario.js) se encarga de hacer la validación de los inputs del formulario y el ultimo (image.js) se encarga de ampliar las imágenes de la página información.html.
